## 🌾 业务场景

本系统模拟农产品从田间到餐桌的完整供应链流程：

```
🌱 生产 → 🏭 加工 → 🚚 物流 → 🏪 销售
```

每个环节的关键数据都以 **区块链交易** 的形式记录上链，通过 **工作量证明 (PoW)** 共识机制生成区块，形成不可篡改的追溯链条。

### 预设演示数据

| 产品 | 类别 | 供应链环节 |
|------|------|-----------|
| 🍎 有机红富士苹果 | 水果 | 生产 → 加工 → 物流 → 销售 |
| 🍚 五常有机大米 | 粮食 | 生产 → 加工 → 物流 → 销售 |
| 🍵 西湖龙井茶叶 | 茶叶 | 生产 → 加工 → 物流 → 销售 |

### 预设参与方

| 角色 | 参与方 |
|------|--------|
| 🌾 生产者 | 阳光生态农场、绿源有机农场 |
| 🏭 加工商 | 鲜品加工厂、绿农食品加工公司 |
| 🚚 物流商 | 顺达冷链物流、京东冷链运输 |
| 🏪 销售商 | 盒马鲜生、永辉超市 |

## 🏗️ 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                   区块链 (Blockchain)                      │
├──────────┬──────────┬──────────┬──────────┬──────────────┤
│  Block #0 │  Block #1 │  Block #2 │  Block #3 │     ...      │
│  (创世)   │           │           │           │              │
│          │          │          │          │              │
│  prev: 0 │ prev: H0 │ prev: H1 │ prev: H2 │              │
│  hash: H0│ hash: H1 │ hash: H2 │ hash: H3 │              │
├──────────┴──────────┴──────────┴──────────┴──────────────┤
│                     交易 (Transactions)                    │
│  🌾 生产记录  🏭 加工记录  🚚 物流记录  🏪 销售记录       │
└─────────────────────────────────────────────────────────┘
```

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 📊 **区块链总览** | 全局概览，展示所有区块与交易数据 |
| 🔍 **产品追溯** | 按产品 ID 追溯全生命周期供应链记录（时间线展示） |
| ➕ **添加交易** | 手动添加生产/加工/物流/销售各环节数据 |
| ⛏️ **挖矿打包** | 将待处理交易通过 PoW 打包生成新区块 |
| ✅ **链验证** | 验证区块链完整性（哈希一致性 + 链式链接 + PoW 证明） |
| 👥 **参与方管理** | 注册/管理供应链各环节参与方 |

## 🚀 快速开始

### 环境要求

- Python 3.8+
- Streamlit

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/your-username/blockchain-supply-chain.git
cd blockchain-supply-chain

# 安装依赖
pip install -r requirements.txt

# 启动系统
streamlit run app.py
```

系统将自动在浏览器中打开 `http://localhost:8501`。

### 使用流程

1. **📊 区块链总览** — 查看区块结构和交易列表
2. **🔍 产品追溯** — 选择产品查看全链路时间线
3. **➕ 添加交易** — 录入新的供应链环节数据
4. **⛏️ 挖矿打包** — 将待处理交易打包上链
5. **✅ 链验证** — 验证区块链完整性
6. **👥 参与方管理** — 管理供应链参与方信息

## 📁 项目结构

```
blockchained_FL/
├── app.py                          # Streamlit 前端应用（主入口）
├── blockchain.py                   # 区块链核心逻辑
├── __init__.py
├── README.md
└── blockchain_data/
    └── blockchain_backup.json      # 区块链数据持久化文件
```

### 核心模块说明

| 文件 | 职责 |
|------|------|
| `app.py` | Streamlit 多页面 UI，包含 6 个功能页面 |
| `blockchain.py` | `Transaction`、`Block`、`Blockchain` 类及 PoW 实现 |

### 数据模型

#### 交易类型 (`Transaction`)

| 类型 | 标签 | 图标 | 关键字段 |
|------|------|------|----------|
| `production` | 生产记录 | 🌾 | 生产者、产地、品质等级、认证信息 |
| `processing` | 加工记录 | 🏭 | 加工商、加工类型、质检结果 |
| `logistics` | 物流记录 | 🚚 | 物流商、运输方式、温度范围 |
| `sale` | 销售记录 | 🏪 | 销售商、门店、售价、上架日期 |

#### 区块 (`Block`)

| 字段 | 说明 |
|------|------|
| `index` | 区块索引 |
| `transactions` | 包含的交易列表 |
| `timestamp` | 时间戳 |
| `previous_hash` | 前置区块哈希 |
| `hash` | 当前区块哈希 |
| `nonce` | 工作量证明随机数 |

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| **Python** | 开发语言 |
| **Streamlit** | 前端界面框架 |
| **SHA-256** | 区块哈希计算 |
| **PoW** | 工作量证明共识（难度 4） |
| **JSON** | 数据持久化存储 |

### 区块链安全特性

- ✅ **SHA-256** 哈希算法确保数据完整性
- ✅ **工作量证明** 防止恶意篡改（前导 4 个零）
- ✅ **链式结构**，每个区块指向前置哈希
- ✅ **自动验证**，任何数据修改都会被检测
- ✅ **JSON 持久化**，支持保存与重载
